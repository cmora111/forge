# Forge Discoveries

## Purpose

The Forge Discoveries directory preserves significant engineering
discoveries made during operation of the Forge.

A Forge Discovery is not a specification.

A Forge Discovery is not a constitutional law.

A Forge Discovery is not a milestone.

A Forge Discovery records an engineering realization whose significance
extends beyond a single engineering project.

Forge Discoveries provide traceability between engineering work and the
principles that eventually emerge from it.

They preserve not only the conclusion, but also the engineering context
in which the conclusion was discovered.

---

## Responsibility

This directory has one exclusive responsibility:

> Preserve methodology discoveries produced by the Forge.

---

## Relationship to Other Artifacts

Constitution
: Defines foundational laws.

Specifications
: Define normative engineering requirements.

Milestones
: Record engineering accomplishments.

Forge Reflections
: Record what a project taught us.

Forge Discoveries
: Preserve methodology discoveries that influence the Forge–Stage Method
itself.
