# Forge Decision Process

Status: Incubating

Version: 0.1.0

---

# Purpose

This document defines the decision process used by the Forge to identify,
evaluate, and resolve engineering uncertainty.

The purpose of this document is not to define engineering principles.

The purpose of this document is to define how the Forge discovers
engineering principles.

---

# Scope

This document describes the process by which the Forge:

- recognizes engineering tension;
- identifies Forge triggers;
- formulates Forge questions;
- evaluates responses;
- determines whether bedrock has been reached.
